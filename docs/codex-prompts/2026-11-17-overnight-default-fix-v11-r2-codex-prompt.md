1. 원인 조사·수정 대상 코드는 동일(main lib 생성 경로 전수). 단, **검증은 프로덕션 본앱을 업데이트 설치해서** 한다.
2. 버전: 설치된 본앱 versionCode 203보다 커야 하므로 검증 빌드는 **versionCode 204**(브랜치에서 pubspec 로컬 bump, 커밋 포함). 실제 배포 시 버전 트레인은 배포 지시에서 다시 계산하므로 이 bump는 검증용.
3. 서명: 본앱과 동일 릴리스 키(android/key.properties + planflow-release.jks — 본앱 워크트리 실측 존재) → **업데이트 설치 시 CEO 실데이터 보존**.
4. 프로덕션 보호 규칙 갱신: **동일 서명 release 업데이트 설치는 허용**(데이터 보존), 언인스톨·데이터 삭제는 금지.

2. 테스트 동일(v11 4단계).
