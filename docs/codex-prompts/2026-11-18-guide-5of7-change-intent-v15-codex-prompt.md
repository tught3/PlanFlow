## Claude 진단 (스크린샷 근거)
- 응답 버블이 조회 결과 뷰 = AI가 이 발화를 **조회 intent로 분류**했거나, 5/7(changeSpeech) 단계의 발화가 변경 파서 대신 조회 파이프라인으로 라우팅됨.
- "변경해줘"가 포함됐는데도 조회로 간 것 → ① intent 분류 프롬프트/규칙이 "첫 번째 일정을 N시로 변경해줘"(서수+시간 변경) 패턴을 변경으로 인식 못 함 ② 또는 대화 화면이 guide changeSpeech 단계임에도 조회 파이프라인을 재사용.
- "5시"(오전/오후 생략) 실패는 별도 겹친 문제: meridiem 추론 부재(기존 일정이 오후 2시면 5시는 오후 5시로 추론해야 자연스러움).
