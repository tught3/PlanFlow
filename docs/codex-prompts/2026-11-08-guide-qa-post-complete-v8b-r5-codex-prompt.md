## Claude 판정 (r4 결과 해석)
- TZ unset(=Dart가 OS 시간대 KST를 그대로 사용) → 5건 **전부 통과**. TZ=Asia/Seoul 명시 → 실패. 이는 **Windows에서 Dart가 TZ 환경변수를 제대로 해석하지 못해 UTC로 떨어지는 알려진 동작**과 일치한다. 즉:
  - **정상 환경(TZ 미조작)에서는 브랜치 코드가 통과한다.**
  - r3 전체 스위트에서 5건이 실패한 것은 그 실행의 환경에 TZ 조작이 섞였다는 뜻(러너 스크립트 등) — 코드 결함이 아니다.
- 게이트의 본질은 "정상 환경에서 머지 트리 실패 ⊆ 기준선 실패"다. r3 전체 실행(78건)의 환경이 오염됐을 수 있으므로, **정상 환경(TZ 미설정) 전체 스위트 1회**로 최종 확정한다.
