# v9-r9 델타 지시 — CEO 발화 단계 제거, Codex 자체 완주 후 최종 확인만 요청 (2026-11-14, Claude 작성)

**정본**: v9-r8 델타. **CEO 신규 지시(2026-11-14, 이후 영구 적용): "테스트 내가 할테니까 테스트하라고 하지 마. 그냥 구현하고 테스트를 나한테 부탁하라고 해." — Codex가 직접 끝까지 자체 검증하고, CEO에게는 최종 확인만 요청한다.**

## 변경
- v9-r8 6단계의 "CEO 발화" 단계를 **전부 제거**한다. CEO는 라운드 중 호출하지 않는다.
- 조회 단계 진행은 **타이핑 경로**(전사 입력 후 제출)로 Codex가 직접 검증한다 — r8의 save 경합 수정으로 타이핑 제출이 가이드 중 정상 동작해야 하며, 이것이 곧 수정 검증이 된다. 조회 발화는 생성 일정 날짜에 맞게("오늘/내일 일정 보여 줘") 입력.
- Codex가 스스로 7/7+마무리까지 도달하는 것이 이번 라운드의 성공 기준이다(타이핑 경로 포함 — 실사용 음성 경로는 최종 확인에서 CEO가 커버).
- 도달 실패 시: dump+logcat 수집 후 보고(Claude 판정) — CEO 호출 금지.
- 7/7 도달 확인 후에만 CEO에게 "최종 실기기 확인(음성 발화 포함 실사용 테스트) 부탁"을 1회 요청한다.

## 절차
v9-r8 절차를 그대로 수행하되 위 변경을 적용: 1~5단계(수정·테스트·머지·재빌드·설치) 동일 → 6단계 4/7 재개 시 CEO 발화 대신 **타이핑 전사 입력+제출**으로 5/7→6/7→7/7→동기화 선택→마무리까지 스스로 진행(각 단계 스크린샷+dump) → 7단계 성공 기준(7/7 도달+마무리+일정 실제 변경 증거) → 8단계 보고에 "CEO 최종 확인 요청" 문구 포함.
