# PlanFlow 개인정보처리방침

최종 업데이트: 2026년 9월 13일

Flux Studio(이하 “회사”)는 PlanFlow(이하 “서비스”) 이용자의 개인정보를 보호합니다. 본 방침은 서비스에서 실제로 처리하는 정보와 이용 목적을 설명합니다.

## 1. 처리하는 정보와 이용 목적

| 정보 | 이용 목적 | 보관·삭제 |
|---|---|---|
| 이메일, 계정 식별자, 설정 | 로그인, 계정 관리, 동기화 | 계정 삭제 시 삭제 |
| 일정, 메모, 그룹 일정과 그룹 댓글 | 일정 관리 및 그룹 협업 | 계정 삭제 시 개인 일정·댓글 삭제. 그룹 공유 일정은 그룹 연속성을 위해 작성자 식별자만 제거되어 남을 수 있음 |
| 음성 인식 결과(텍스트), 일정 입력 텍스트 | 일정 구조화, AI 기능 제공 | 계정 삭제 시 관련 로그·일정 삭제 |
| 장소명 및 이동시간 계산에 필요한 위치 정보 | 장소 표시와 출발 알림 계산 | 계정 삭제 시 저장된 위치 기록 삭제. 계산 중 현재 위치·목적지 좌표가 TMAP, Naver 또는 Google 경로 서비스로 전송될 수 있음 |
| Google/Naver 캘린더 연동 토큰과 일정 | 캘린더 연동 | 계정 삭제 시 삭제 |
| 오류·성능·설치 진단 정보 | 서비스 안정성 개선 | Firebase Crashlytics 정책에 따라 처리되며, Crashlytics 충돌 데이터의 기본 보관기간은 90일임 |
| 광고 요청·노출 관련 정보 | 보상형 광고 제공 | Google Mobile Ads/UMP 정책에 따라 처리 |

원시 음성은 기기 내 음성 인식으로 처리하며 Flux Studio 서버에 전송하거나 저장하지 않습니다. 인식된 텍스트는 Supabase 서버 기능을 통해 OpenAI에 전달될 수 있고, 일정 생성 및 음성 로그에 저장될 수 있습니다. OpenAI API는 기본적으로 모델 학습에 이용하지 않으며, 제공자의 남용 모니터링 로그는 기본적으로 최대 30일 보관될 수 있습니다.

자동 백업은 최근 30일 및 월별 롤업을 최대 365일까지 유지하고, 사용자가 만든 수동 백업은 삭제할 때까지 유지합니다. 프로젝트 복구 스냅샷은 최근 35일 및 월별 스냅샷 최대 12개월의 순환 정책으로 운영될 수 있습니다. 계정 삭제가 이미 생성된 복구 스냅샷을 즉시 제거하지 않을 수 있으며, 해당 스냅샷은 순환 만료에 따라 삭제됩니다.

계정 삭제 시 본인이 만든 그룹 백업은 삭제합니다. 다른 그룹 리더가 만든 그룹 백업 스냅샷에는 탈퇴한 사용자의 그룹 데이터가 해당 백업 생성자가 삭제할 때까지 남을 수 있으며, 그룹 백업에 대해 확인된 자동 보관기간은 없습니다.

## 2. 제3자 서비스와 국외 처리

서비스 제공을 위해 Supabase, OpenAI, Google(로그인·캘린더·Firebase·Mobile Ads/UMP·Maps), Naver(로그인·캘린더·지도), TMAP을 사용할 수 있습니다. 주 저장소인 Supabase 프로젝트는 일본(도쿄) 리전에 있습니다. Google과 OpenAI의 글로벌 인프라를 통해 대한민국 밖에서 처리될 수 있으며, 실제 처리 국가는 단일 국가로 고정되지 않습니다. 국외 처리는 해당 기능을 사용할 때 암호화된 네트워크 전송으로 이루어지고, 보관기간은 위 표와 각 제공자의 정책·서비스 설정을 따릅니다. 지도·경로 제공자는 요청된 장소·좌표와 경로 계산 정보를 처리할 수 있습니다.

## 3. 광고와 추적

iOS에는 추적 사용 설명 문자열이 포함되어 있으나, 현재 앱 소스에는 ATT 권한 요청이나 IDFA 직접 접근이 없습니다. Google UMP는 설정된 동의 메시지에 따라 ATT 관련 안내를 표시할 수 있고, Google Mobile Ads의 광고 식별자·추적 관련 처리는 운영 설정과 동의 상태에 따라 달라질 수 있습니다. 해당 운영 설정을 확인한 뒤 App Store 개인정보 공개 항목을 실제 처리와 일치시킵니다. 계정·일정 같은 기본 기능은 광고 동의와 관계없이 이용할 수 있으나, 광고 시청을 전제로 한 추가 이용 기회는 제공되지 않을 수 있습니다. 운영 iOS 광고 단위는 원격 설정으로만 주입하며 본 방침에 식별자를 공개하지 않습니다.

## 4. 아동 및 그룹 콘텐츠

서비스는 만 14세 미만 아동을 대상으로 설계하거나 제공하지 않습니다. 공개 게시판이나 공개 피드는 운영하지 않습니다. 인증된 그룹 구성원 사이의 일정과 댓글은 제한된 그룹 협업 콘텐츠로 공유되며, 계정 탈퇴 시 작성 댓글은 삭제됩니다. 부적절한 콘텐츠 신고가 필요하면 아래 연락처로 신고해 주세요.
