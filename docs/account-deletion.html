PlanFlow 계정 및 데이터 삭제 안내

이 문서는 FluxStudio가 제공하는 PlanFlow 앱의 계정 삭제와 사용자 데이터 삭제 요청 방법을 안내합니다.

가장 빠른 방법: 앱에서 회원 탈퇴

계정 삭제는 앱 안에서 바로 처리되며 별도의 요청이나 대기 시간이 필요하지 않습니다.

설정 → 계정 → 회원 탈퇴

  1. PlanFlow 앱을 실행하고 하단 메뉴에서 설정을 엽니다.
  2. 계정 메뉴를 선택합니다.
  3. 회원 탈퇴를 누릅니다.
  4. 탈퇴 안내 문구를 확인한 뒤 본인 확인을 거쳐 탈퇴를 완료합니다.
  5. 탈퇴가 완료되면 로그인 화면으로 돌아가며 계정과 개인 데이터가 삭제됩니다.
[스크린샷: 설정 → 계정 → 회원 탈퇴]
⚠️ 탈퇴 전에 확인하세요 회원 탈퇴 후에는 계정을 다시 복구할 수 없습니다. 탈퇴 전에 필요한 일정이나 데이터를 미리 백업해 두시기 바랍니다.

앱에 접근할 수 없는 경우

앱에 접근할 수 없어 앱 내에서 회원 탈퇴를 진행할 수 없다면, 아래 정보를 포함해 contact@fluxstudio.co.kr으로 이메일로 요청해 주세요.

  • 메일 제목: PlanFlow 계정 삭제 요청
  • PlanFlow에 로그인한 계정 이메일 주소
  • 사용자 이름
  • 삭제 요청 범위: 계정 전체 삭제

요청을 확인한 뒤 본인 확인이 필요한 경우 추가 확인을 요청할 수 있으며, 확인이 완료되면 계정과 앱 서비스 제공에 필요한 사용자 데이터를 삭제합니다.

삭제되는 데이터

계정 전체 삭제 시 다음 PlanFlow 데이터가 삭제됩니다.

  • 로그인 계정 정보와 앱 프로필 정보
  • 개인 일정, 준비 항목, 알림/알람 예약
  • 음성 입력에서 변환된 텍스트 음성 로그와 일정 분석 기록
  • 위치 기록
  • 캘린더 연동 상태, 네이버 CalDAV 연결 정보, 앱 설정
  • 앱 백업 및 복원 데이터
  • 앱 내부 문제 신고와 피드백 내역 중 계정과 연결된 데이터

유지되는 데이터

그룹 기능으로 다른 멤버와 공유한 일정 중 그룹이 유지되는 경우, 해당 데이터는 삭제되지 않고 그룹에 남아 다른 멤버가 계속 이용할 수 있습니다. 이는 공유 일정을 만든 다른 멤버들의 이용 권리를 보호하기 위한 조치입니다.

  • 그룹 공유 일정 (다른 멤버의 권리 보존)

그룹 리더 주의사항

⚠️ 그룹 리더인 경우 그룹 리더인 경우, 회원 탈퇴 전에 그룹을 삭제하거나 리더를 다른 멤버에게 위임해야 합니다.

탈퇴 시점에 리더인 그룹이 남아 있으면 그룹 운영이 중단될 수 있으므로, 탈퇴 전에 반드시 아래 방법으로 정리해 주세요.

앱 내 그룹 관리 → 멤버 → 리더 위임

  1. 그룹 화면에서 그룹 관리를 엽니다.
  2. 멤버 목록에서 리더를 위임할 멤버를 선택합니다.
  3. 리더 위임을 실행합니다.

그룹을 더 이상 유지하지 않는다면, 리더 위임 대신 해당 그룹을 삭제한 뒤 회원 탈퇴를 진행하면 됩니다.

처리 기간

  • 앱 내 회원 탈퇴: 즉시 처리됩니다.
  • 이메일 요청: 영업일 기준 3~5일이 소요될 수 있습니다.

보관될 수 있는 데이터와 보관 기간

법적 의무, 보안 감사, 부정 이용 방지, 고객 지원 이력 확인을 위해 일부 기록은 필요한 범위에서 최대 90일간 보관될 수 있습니다. 보관 기간이 끝나면 삭제하거나 개인을 식별할 수 없도록 처리합니다.

계정 삭제 없이 일부 데이터 삭제 요청

계정은 유지하고 일부 데이터만 삭제하고 싶다면 앱 안에서 일정을 직접 삭제하거나, 아래 정보를 포함해 같은 이메일 주소로 요청해 주세요.

  • 메일 제목: PlanFlow 데이터 삭제 요청
  • PlanFlow에 로그인한 이메일 주소
  • 삭제하려는 데이터 유형: 일정, 백업, 음성 로그, 캘린더 연동 정보, 문제 신고 등
  • 삭제 대상 기간 또는 구체적인 설명

일부 데이터 삭제는 앱 기능 유지에 필요한 최소 계정 정보는 남긴 상태로 처리됩니다.
