# lib/shared

여러 feature에서 공통으로 재사용되는 코드를 배치합니다.

## 디렉토리 구조

| 디렉토리         | 용도                                                |
| ---------------- | --------------------------------------------------- |
| `widgets/`       | 앱 전역에서 사용하는 재사용 가능한 UI 위젯         |
| `utils/`         | 날짜/문자열/포맷 등 범용 유틸리티 함수             |
| `constants/`     | 앱 공통 상수 (여백, 둥근 모서리 값, 경로 등)       |
| `extensions/`    | BuildContext, String, DateTime 등 확장 메서드      |

## 규칙

- 이 디렉토리의 코드는 특정 feature에 종속되지 않아야 합니다.
- feature 전용 코드는 `lib/features/<feature>/` 아래에 작성하세요.
- core 인프라(라우터, 테마, 환경설정 등)는 `lib/core/` 에 유지합니다.
